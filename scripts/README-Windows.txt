OfficeChat for Windows (portable version)
=========================================
Tip: if you can, use OfficeChat-Setup.exe instead. It installs the app
properly (shortcuts, uninstaller, firewall) in one step.

1. Copy this folder anywhere (e.g. C:\OfficeChat or your Desktop).
2. Double-click OfficeChat.exe. The OfficeChat window opens.
   If Windows says "Windows protected your PC": click More info > Run anyway.
3. When Windows Firewall asks, tick BOTH "Private" and "Public" and click Allow.
   Missed it? Right-click "Allow OfficeChat through firewall.bat" > Run as
   administrator, or use Settings > "Allow OfficeChat through Windows Firewall".

Everyone on the same Wi-Fi/LAN with the same team key appears automatically.
Received files are saved in Downloads\OfficeChat.
Closing the window keeps OfficeChat running in the system tray (near the
clock) so you still receive messages. Right-click the tray icon > Quit to exit.

Start automatically with Windows: press Win+R, type  shell:startup , and put
a shortcut to OfficeChat.exe in that folder.
